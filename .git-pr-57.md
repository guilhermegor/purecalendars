## Description  
**What**: Adopt the BlueprintX `lib-minimal` `.specs/` layout and its two gates (`specs-structure`, `docs-boundary`). Work trackers leave `docs/` and live under `.specs/`, grouped per feature.  
**Why**: `docs/` is for published documentation only; excluding `docs/backlog/` from the MkDocs build was camouflage for a boundary violation. Both gates edit the same hook and CI step lists, so they land together. Where the repo and the template differ, the template wins.  
**How**: Template files copied as written (BlueprintX `origin/main` at `5a29234e`): `bin/ci/check_specs_structure.sh`, `bin/ci/check_docs_boundary.sh`, `templates/python-common/bin/check_backlog_ledger.py`, `templates/common/.specs/AGENTS.md` (as `.specs/CLAUDE.md`, since this repo has no `AGENTS.md` pairs).
